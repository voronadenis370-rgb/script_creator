🔍 Поиск в памяти

gg.searchNumber(text, type [, encrypted, sign, memoryFrom, memoryTo]) — основной метод поиска.

Типы:

  • gg.TYPE_BYTE (1) — флаги, маленькие счётчики
  • gg.TYPE_WORD (2) — 2 байта
  • gg.TYPE_DWORD (4) — патроны, очки, HP (целые)
  • gg.TYPE_FLOAT (16) — скорость, гравитация, координаты
  • gg.TYPE_QWORD (32) — большие целые
  • gg.TYPE_DOUBLE (64) — точная валюта, double-координаты
  • gg.TYPE_XOR — зашифрованные значения
  • gg.TYPE_BYTE | gg.TYPE_WORD | ... — комбинированный поиск

Уточнение поиска: gg.refineNumber(text, type) — фильтрует уже найденные результаты.

gg.setRanges(gg.REGION_ANONYMOUS) gg.searchNumber("100;50;25::", gg.TYPE_DWORD) -- group search gg.refineNumber("100", gg.TYPE_DWORD) local count = gg.getResultsCount() local r = gg.getResults(100)

✏️ Редактирование и заморозка

gg.editAll(value, type) — меняет все текущие результаты.

gg.setValues(table) — точечная запись по адресам.

gg.getValues(table) — чтение текущих значений по адресам.

Заморозка: добавьте freeze = true (или freezeType) и вызовите gg.addListItems(t).

local t = {} for i, v in ipairs(r) do t[i] = { address = v.address, flags = gg.TYPE_DWORD, value = 9999, freeze = true } end gg.setValues(t) gg.addListItems(t) gg.clearResults()

📐 Смещения (Offsets)

Структуры в памяти: найдя base-адрес, вычисляете соседние поля.

Формула: address = base + 0xOffset

gg.searchNumber("100", gg.TYPE_DWORD) local r = gg.getResults(20) local patches = {} for i, v in ipairs(r) do patches[i] = { address = v.address + 0x14, -- offset 0x14 flags = gg.TYPE_DWORD, value = 99999 } end gg.setValues(patches)

Часто используют цепочки указателей (pointer chains) для стабильных адресов между перезапусками.

💬 Диалоги и меню

gg.toast(text) — неблокирующее уведомление.

gg.alert(text [, positive, negative, neutral]) — модальный диалог.

gg.choice(items, selected, message) — список выбора (возвращает индекс 1-based или nil).

gg.prompt(fields, defaults, types) — ввод значений пользователем.

while true do local ch = gg.choice({"Патроны","Скорость","Выход"}, nil, "Меню") if ch == nil then elseif ch == 3 then break elseif ch == 1 then -- ... end end

⏱️ Тайминги

gg.sleep(ms) — пауза потока. Нужна после поиска/записи на больших списках, чтобы избежать крашей и дать игре обновить память.

gg.searchNumber("50", gg.TYPE_FLOAT) gg.sleep(250) gg.editAll("999", gg.TYPE_FLOAT) gg.toast("Готово")

🗺️ Регионы памяти

  • gg.REGION_ANONYMOUS — динамические данные (самый частый выбор)
  • gg.REGION_C_ALLOC — malloc/куча
  • gg.REGION_C_DATA / C_BSS — статика
  • gg.REGION_JAVA / JAVA_HEAP — Java-куча
  • gg.REGION_CODE_APP / CODE_SYS — код (осторожно)
  • gg.REGION_PPSSPP, REGION_VIDEO и др.

Комбинирование: gg.setRanges(gg.REGION_ANONYMOUS | gg.REGION_C_ALLOC)

⚡ Speedhack

gg.setSpeed(speed) — множитель скорости игры (1.0 = норма, 2.0 = x2, 0.5 = замедление).

gg.setSpeed(3.0) -- ускорение x3 gg.sleep(5000) gg.setSpeed(1.0) -- вернуть нормальную скорость

Работает не во всех играх (зависит от способа отсчёта времени в движке).

🚀 Продвинутые возможности

  • gg.getTargetInfo() — информация о процессе
  • gg.getFile() / gg.getLine() — путь и строка скрипта
  • gg.copyMemory(from, to, size) — копирование памяти
  • gg.searchPointer(maxOffset) — поиск указателей
  • gg.loadResults(table) / gg.saveList() — работа со списками
  • gg.makeRequest(url) — HTTP-запросы (для обновлений скрипта)
  • gg.setVisible(false) — скрыть интерфейс GG
  • gg.processKill() / gg.processToggle()
  • Hex-поиск: gg.searchNumber("h 48 8B 05", gg.TYPE_BYTE)
local info = gg.getTargetInfo() gg.toast(info.packageName .. " pid:" .. info.pid) gg.setVisible(false) -- спрятать GG

🛡️ Защита кода

Базовая обфускация — перевод исходника в hex-строку и выполнение через load().

local code = "\x67\x67\x2e\x74\x6f\x61\x73\x74\x28\x22\x48\x69\x22\x29" load(code)()

Можно вкладывать load несколько раз, удалять комментарии и пробелы. Это не криптография, но сильно усложняет чтение скрипта «на глаз».
