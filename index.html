1. Сканирование памяти (gg.searchNumber)
Функция производит поиск значений в оперативной памяти устройства. Выбор правильного типа данных критически важен:
• DWORD (gg.TYPE_DWORD): Целые 4-байтовые числа (Патроны, Здоровье, Уровень).
• FLOAT (gg.TYPE_FLOAT): Дробные числа (Скорость движения, Гравитация, Высота прыжка).
• BYTE (gg.TYPE_BYTE): Однобайтовые числа и флаги/переключатели (0 или 1, вкл/выкл).
• DOUBLE (gg.TYPE_DOUBLE): Высокоточные 8-байтовые дробные числа (Игровая валюта в онлайн играх).
Ограничение регионов ОЗУ ускоряет поиск: gg.setRanges(gg.REGION_ANONYMOUS). 
gg.setRanges(gg.REGION_ANONYMOUS)
gg.searchNumber("100", gg.TYPE_DWORD)
2. Модификация и Заморозка Памяти
Массовое редактирование gg.editAll заменяет все найденные адреса. Точечная установка gg.setValues изменяет конкретные адреса в массиве. Для заморозки значения используется флаг freeze = true в комбинации с регистрацией элементов в памяти через gg.addListItems(). 
-- Пример заморозки найденных значений
local r = gg.getResults(100)
for i, v in ipairs(r) do
    v.value = '999999'
    v.freeze = true
end
gg.addListItems(r)
3. Работа со смещениями (Offsets)
В структуре памяти связанные параметры (например, X, Y, Z координаты или Здоровье и Броня) находятся на фиксированных расстояниях от базового адреса (baseAddress). Смещение задается в 16-ричной системе (Hex). Формула применения: item.address + 0xOffset. 
local r = gg.getResults(1)
local patches = {}
table.insert(patches, {
    address = r[1].address + 0x14, -- Смещение +20 байт
    flags = gg.TYPE_DWORD,
    value = 5000
})
gg.setValues(patches)
4. Диалоги, Уведомления и Бесконечный Цикл
• gg.toast("текст") — всплывающая подсказка внизу экрана (не ставит игру на паузу).
• gg.alert("текст") — модальное окно с кнопкой OK.
• Бесконечный цикл while true do ... end в связке с gg.isVisible(true) позволяет меню повторно открываться при нажатии на иконку Game Guardian. 
while true do
    if gg.isVisible(true) then
        gg.setVisible(false)
        MainMenu()
    end
    gg.sleep(100)
end
5. Тайминги и Защита Скриптов
• gg.sleep(ms) — приостанавливает выполнение скрипта на указанное количество миллисекунд. Задержки предотвращают вылеты игры при интенсивных операциях записи в память.
• Защита кода осуществляется превращением исходного текста в Hex-последовательность символов вида \xXX и вызовом динамического компилятора load()(). 
local code = "\x67\x67\x2e\x74\x6f\x61\x73\x74\x28\x22\x48\x65\x6c\x6c\x6f\x22\x29"
load(code)()
